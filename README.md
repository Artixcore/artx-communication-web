# ARTX Communication Web

Official Next.js web client for the ARTX Network.

This repository is intentionally separated from the Go backend (`Artixcore/artx-communication-server`) and Android client (`Artixcore/artx-communication`). Public discovery, public AID profiles, public research/projects and other explicitly public knowledge surfaces may be accessible without authentication. Editing, settings, account/security, private workspace data and other user-private surfaces require authenticated, server-authorized access.

Development follows the ARTX 30-day Beta release train coordinated from `Artixcore/artixcore-central-command`.
